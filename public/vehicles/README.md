# Vehicle images

Drop car photos here — ideally "a survivor standing next to the car" shots.

Filenames (referenced from `src/data/vehicles.ts`):

- `sarka-120.webp`
- `olga-24.webp`
- `gunter-2.webp`
- `ada-4x4.webp`
- `m3s-truck.webp`

These are currently populated with the vehicle photos from the DayZ wiki
(https://dayz.fandom.com/wiki/Vehicles, hosted on the fandom `dayz_gamepedia`
image CDN). Swap in your own screenshots — ideally "a survivor standing next to
the car" shots — if you hit licensing concerns; just keep the filenames.

If a file is missing, the vehicle card falls back to a labeled placeholder box,
so the site still works.
